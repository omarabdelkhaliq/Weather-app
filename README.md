# 🌦️ Weather App

A weather application that allows users to check weather information for different locations through a simple and user-friendly interface.

## 🚀 Live Demo

[View the Live Demo](https://omarabdelkhaliq.github.io/Weather-app/)

## ✨ Features

- Search for weather information by city.
- Display current weather conditions.
- Show temperature and other weather details.
- Simple and intuitive user interface.
- Responsive layout for different screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Weather API

## 📚 What I Learned

- Fetching weather data from an API.
- Working with asynchronous JavaScript.
- Handling user input and search functionality.
- Displaying dynamic data in the DOM.
- Handling API responses.
